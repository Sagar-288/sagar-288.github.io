Privacy · Effective August 1, 2026

Your files stay private. Analytics stays optional.

Morph processes files on your iPhone and never sends filenames or file contents for analytics. You decide whether to share metadata-only usage statistics.

No file uploadsYour source files and results are not sent to the analytics service.
Opt-in analyticsOff unless you choose to share anonymous usage statistics.
Delete anytimeDisable collection or delete this installation’s analytics in Settings.

1. Scope

This policy applies to Morph for iOS version 1.0. Morph converts and edits files without requiring an account. File processing remains on your device unless a specific future server conversion clearly asks for permission first.

2. Files and edits

Source files are read only after you choose them. Results are saved in Morph’s private app storage or to a destination you explicitly select, such as Photos or Files.

Morph does not upload or retain a server copy of your source files or results for analytics.

3. Optional anonymous analytics

Morph asks during onboarding whether you want to share anonymous usage statistics. Analytics is off unless you choose Share anonymous stats, and you can turn it off later in Settings.

When enabled, Morph sends:

  • a randomly assigned anonymous installation identifier and the iOS Identifier for Vendor (IDFV);
  • device model, iOS version, Morph version, and platform;
  • source and target format, a coarse file-size range, on-device or server execution, duration, success/cancellation/error outcome, a stable error code, and coarse edit-operation names; and
  • country and region inferred by Morph’s server from the request IP address.

Each event has a random identifier used only to prevent a retry from being counted twice. Analytics helps measure format demand, reliability, performance, device compatibility, and broad regional usage.

Never included: filenames, paths, file contents, content hashes, EXIF, exact file sizes, precise dimensions, precise location, contacts, advertising identifiers, or account information.

Analytics is not used for advertising, cross-app tracking, marketing profiles, or sale to data brokers.

4. IP address handling

The server uses the request IP transiently to derive a coarse country/region and apply a short abuse-prevention rate limit. The IP address itself is not stored in the analytics database or written to application logs. Only the derived coarse country and region are retained with an event.

5. Information stored on your device

Morph stores converted files kept in the Morph library, app preferences, the home-screen layout, and—only after analytics consent—an offline analytics queue. Turning analytics off clears that queue. Deleting Morph removes its app sandbox, except for copies previously exported elsewhere.

Home-layout cloud sync is disabled in version 1.0; the layout remains on device.

6. Retention, choices, and deletion

Analytics events are automatically deleted from Morph’s server within 180 days. Stop new collection under Settings → Share anonymous usage stats.

Settings → Delete analytics data removes queued events and requests deletion of analytics associated with that installation from Morph’s server. If the request cannot connect, Morph reports that it was not completed so you can retry.

You can also request assistance at skalsaria288@gmail.com. Morph has no accounts, so the in-app control may be needed to prove control of the anonymous installation token.

7. Service providers and security

Morph does not include advertising SDKs or third-party analytics SDKs. Its metadata-only analytics API and database use Microsoft Azure as infrastructure supporting Morph. Data travels over HTTPS, raw event storage is restricted to the backend, and the operator dashboard exposes aggregates behind authentication.

8. Permissions

Morph may request Photos, Camera, or Microphone access only when you use a feature that needs it. You can change these permissions in iOS Settings. Analytics never includes media obtained through these permissions.

9. Children

Morph is not directed to children under the minimum age required to consent to data processing in their country. It does not knowingly collect contact details or account information from children. A parent or guardian can disable analytics or use the deletion control above.

10. Changes

This policy and the App Store privacy disclosure will be updated before Morph materially changes its data practices. The effective date identifies the current version.

11. Contact

Privacy questions can be sent to skalsaria288@gmail.com. You can also visit Morph Support.
